## Publish for free using GitHub Pages

1. Sign in or create an account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`, replacing the placeholder with your actual GitHub username (keep the `.github.io` suffix).
3. Upload **`index.html`, `styles.css`, `script.js`, and `.nojekyll`** from this folder to the root of the new repository (you can also add this README).
4. Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Once publishing finishes, visit `https://YOUR-GITHUB-USERNAME.github.io/`.
6. Submit that address in Whitecliffe's portfolio field.

If you prefer a repository named `portfolio`, the URL will instead be `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`.

### Local preview

Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000/.
